### What I'm building now

- **[signal-problems](https://github.com/AlanJuker/signal-problems)**: is it really "signal problems"? I turned
  the TTC's 260,000-row delay log into an API, an interactive subway map and a commute check. Since 2014, only
  3.6% of subway delays of 5+ minutes were signal failures. A delay model beats the historical frequency on
  held-out data, and the project now covers streetcar and bus routes too.
- **[noc-noc](https://github.com/AlanJuker/noc-noc)**: newcomers to Canada must name their NOC occupation code
  for Express Entry and work permits, and job titles rarely match the official ones. noc-noc finds it from a
  job title: the right code is in its first five answers for 93.6% of 5,468 held-out official titles.
